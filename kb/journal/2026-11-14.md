## How it started

The idea came up in another repo: build our own programming language, as flexible as Go and as usable for
data and AI as Python. Do it in public, learn every layer along the way, document all the research here,
and get real people testing it.

## Decided

- **Implementation language: Rust** ([ADR 0001](../decisions/0001-implementation-language-rust.md)).
  Go was the other strong option, since it's already familiar.
- **Name: Pings**, the CLI `pings`, source files `.pi`. It took four tries, and every rejection was a collision:
  - *Quill*, `.ql`: `.ql` is CodeQL's extension, and `quill` on crates.io is a plotting library.
  - *PLang*, `.pl`: `.pl` has been Perl's extension since 1987 (Prolog's too), and a language called Plang already exists.
  - *Sway*, `.sw`: Fuel Labs' Sway is a programming language (61k GitHub stars, also Rust, `.sw` files), and Sway is also a well-known Linux window manager.
  - *Pings*, `.pi`: no language with this name; `.pi` isn't in GitHub Linguist; `pings` is free on crates.io.
  - Lesson: check GitHub, the package registries, Linguist's extension list, and existing languages before announcing a name.
- **The repo is public from day one:** github.com/Prathameshppawar/pings

## Built

- A Cargo workspace with the `pings` binary (`--help`, `--version`) and 3 integration tests.
- Pinned Rust toolchain (1.99.0); workspace-wide `unsafe_code = "deny"`.
- CI: fmt, clippy (`-D warnings`), and tests on Linux, macOS, and Windows, with Actions pinned by SHA.
- Knowledge base: vision, roadmap, ADRs 0001–0004, six research notes, reading list, glossary.
